# Modul Usaha dan Energi Interaktif

Buka index.html untuk menggunakan modul. Semua aset disertakan. Untuk penggunaan konsisten dan penyimpanan progres, gunakan alamat GitHub Pages yang sama setiap kali.

## Publikasi GitHub Pages
1. Buat repository GitHub baru, misalnya modul-usaha-energi.
2. Unggah seluruh isi folder ini (index.html, app.js, style.css, assets), bukan ZIP-nya.
3. Buka Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Alamat biasanya https://USERNAME.github.io/modul-usaha-energi/ . Gunakan alamat yang diberikan GitHub.

Progres tersimpan di localStorage browser masing-masing, bukan berdasarkan IP dan bukan di repository. IP bisa berubah atau dipakai bersama. Data tidak tersinkron antarbrowser/perangkat; gunakan Unduh/Pulihkan progres. Tidak ada pengumpulan jawaban guru atau penilaian otomatis.

Halaman asli dipertahankan sebagai gambar. Jawaban diketik dan digambar pada lapisan di atas gambar. Mode klik pilihan melingkari lokasi yang diklik, bukan pemeriksaan benar/salah. Urungkan menghapus goresan terakhir; jika tidak ada goresan, menghapus kotak teks terakhir. Cetak mencetak halaman aktif beserta jawaban. Browser belum diuji secara visual pada perangkat siswa.
